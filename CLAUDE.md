# Igrališta Tuzla — Project Context

A static single-page website for a civic initiative to restore children's playgrounds in Tuzla. The goal of the site is to attract association founders, donors, and support from the City of Tuzla.

## Quick Overview

- **Domain:** igralista-tuzla.com (GoDaddy → GitHub Pages)
- **Repo:** github.com/igralistatuzla-web/igralista-tuzla
- **Contact:** igralistatuzla@gmail.com
- **Language:** Bosnian (Latin script)
- **Technologies:** plain HTML + CSS + JS, no build step, no framework

## File Structure

```
.
├── index.html      # entire site, with <style> and <script> inline
├── assets/         # photo assets (real playground photos for the gallery)
│   └── IMG_*.jpeg
├── README.md       # deploy instructions for GitHub Pages
├── CNAME           # (auto-generated by GitHub Pages, contains only the domain)
└── CLAUDE.md       # this file
```

Everything is intentionally kept in a single `index.html` so that deployment is trivial and someone who is not a programmer can open the file directly on GitHub, click the pencil icon, and edit the text without any build pipeline.

## Design Philosophy

Editorial, warm palette, serious tone without corporate sterility. The site goes before the City and potential donors — it must be professional enough to be taken seriously, warm enough to convey that it's about children.

Aesthetic reference: a printed magazine / nonprofit annual report, not a tech startup landing page.

### Design Tokens (already defined in `:root` in index.html)

```
--cream:        #f6f0e4   /* main background */
--cream-deep:   #ece3cf   /* darker section background */
--cream-soft:   #fbf7ee   /* lighter section background */
--ink:          #1c2a1f   /* main text, dark sections */
--ink-soft:     #2f3b30   /* secondary text */
--moss:         #3f5a3a   /* eyebrows, subtle accent */
--terracotta:   #c2542d   /* main accent, italic em in h2 */
--sun:          #e9b94a   /* yellow pop, used on dark/terracotta backgrounds */
--sage:         #9aac86   /* tertiary accent */
```

### Fonts

- **Display (Fraunces):** for h1, h2, h3, numbers. Variable font with `opsz` and `SOFT` axes — use `font-variation-settings` to adjust optical size and softness.
- **Body (Manrope):** for everything else.

Both are loaded from Google Fonts in the head — do not touch unless changing the entire typographic palette.

### Rules That Must Not Be Broken

- **Em inside h2:** `<em>accent</em>` in headings produces an italic terracotta word. Exception: in `.locations` (dark background) and `.involve` (terracotta background) there are overrides — `em` is `var(--sun)` on terracotta.
- **Reveal animation:** the `.reveal` class on elements that should appear on scroll; the observer is in the `<script>` at the bottom. Respects `prefers-reduced-motion`.
- **Mobile breakpoint:** the main one is 760px, secondary 860px for grid collapses.

## Site Sections (in order)

1. **Nav** — sticky, blur backdrop, brand with SVG swing
2. **Hero** — title, lead, CTA, illustration (SVG swing + sun)
3. **Problem** — 3 statistics on cream-deep background
4. **Gallery** (`#galerija`) — 17 real photos of current playground state, responsive grid, click-to-lightbox
5. **Goals** — 6 items in a 2-column grid
6. **Locations** — 5 pilot neighbourhoods + Phase II, on ink (dark) background
7. **Budget** — cost table for renovating one playground
8. **Financing** — 4 pillars (donations, City, crowdfunding, grants)
9. **Programs** — 6 long-term programs with SVG icons
10. **In the Media** — 6 articles from Tuzla media in 2 groups
11. **Get Involved** — 3 CTA cards on terracotta background, mailto links
12. **Footer** — contact, navigation, copyright

Section IDs are in kebab-case Bosnian: `#problem`, `#ciljevi`, `#lokacije`, `#budzet`, `#programi`, `#mediji`, `#ukljuci-se`, `#kontakt` (footer).

## Content Sources

Texts and data come from two project documents the user has in their folder (Word + PDF — `Prijedlog_projekta.docx`, `Prijedlog_projekta_Igralista_Tuzla_*.pdf`). Do not invent new statistics or claims — everything must be grounded in those documents or in real media sources.

Links in the "In the Media" section are verified and focused exclusively on Tuzla (Tuzlanski.ba, Tuzla L!VE). Do not add articles from other cities unless a separate "good practices from the region" section is being created.

### Important Facts That May Change

- **PA.CON II (February 2026):** The City of Tuzla has already installed inclusive equipment at 9 locations. This means the claim "no playground is adapted for children with disabilities" is no longer **accurate**. The current statistic on the site ("0 / all") is technically incorrect, but has been kept so far because 7 swings for the entire city is still minimal. If the City publicises this, the wording must be more careful — e.g. "the first inclusive elements only from 2026, at 9 out of over 100 playgrounds".

## How to Edit Text

Open `index.html` in an editor, search for the text you want to change, modify it, and save. Do not touch the structure (HTML tags, classes) unless you are adding a new section.

For a new section, follow the existing convention:
- HTML comment separator above: `<!-- ============... NAME ============... -->`
- `<section id="..." class="...">` with `.container` inside
- `.section-head.reveal` for the header with eyebrow + h2
- `.reveal` on all elements that should animate
- CSS rules go in the main `<style>` block at the top, with the same comment separators

## Workflow

```bash
# Local preview
python3 -m http.server 8000
# then http://localhost:8000

# Push changes
git add .
git commit -m "short description"
git push

# GitHub Pages deploys automatically within 1-2 minutes
```

Changes are visible at `https://igralista-tuzla.com` after deployment. If they don't appear immediately — hard refresh (Cmd+Shift+R) due to cache.

## What NOT to Do

- Do not introduce React, Vue, Tailwind, or any build tool — the single-file approach is a deliberate decision
- Do not add libraries other than Google Fonts
- Do not change the colour palette without a reason — the palette is part of the identity
- Do not add themes or dark mode — the site has one clear aesthetic
- Do not write in first-person plural with a political tone ("we will solve...") — the tone is informative, civic, not partisan
- Do not add emoji to the site text (unless there is a direct need)
